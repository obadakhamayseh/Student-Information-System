# بوابة الطالب الذكية - جامعة مؤتة (Mutah SIS Modern Portal)

تطبيق ويب عصري عالي الأداء مصمم كواجهة بديلة وفائقة التطور لنظام معلومات الطلبة في **جامعة مؤتة** (`https://app.mutah.edu.jo/studreg/`).

---

## المبادئ الأساسية والأمان (Security by Design)

- **انعدام التخزين الدائم (Zero Data Retention):** لا توجد أي قاعدة بيانات ولا IndexedDB ولا localStorage للبيانات الأكاديمية أو بيانات الاعتماد.
- **حماية كلمة المرور:** كلمة المرور تمر لحظياً فقط في الذاكرة لتنفيذ طلب المصادقة ولا تُحفظ أو تُسجّل إطلاقاً.
- **جلسة مشفرة (Encrypted Session):** كوكيز الجلسة الأصلية (`JSESSIONID`, `BNIS_*`, `BNES_JSESSIONID`) تُحفظ في كوكي مشفرة تماماً عبر مكتبة `iron-session` بتقنية AES-256 (httpOnly, SameSite=Lax/Strict).
- **كشف تلقائي لانتهاء الجلسة:** تحويل ذكي لإعادة توجيه `302 session_expired` من الخادم إلى صفحة الدخول فوراً.

## المعمارية البرمجية (BFF Architecture)

```text
src/
├── app/                          # مسارات Next.js (App Router)
│   ├── (auth)/login/             # صفحة الدخول العصرية مع التحقق البشري الحي
│   ├── (dashboard)/              # الصفحات المحمية (تشترك في شريط التنقل)
│   │   ├── dashboard/page.tsx    # لوحة التحكم ومعدل التراكمي ونسبة الإنجاز
│   │   ├── grades/page.tsx       # السجل الأكاديمي الشامل وفلاتر البحث
│   │   ├── schedule/page.tsx     # جدول الامتحانات والمحاضرات الأسبوعية
│   │   └── plan/page.tsx         # الخطة الشجرية والمواد المتبقية
│   └── api/                      # Route Handlers (طبقة BFF)
│       ├── auth/                 # captcha, login, logout, me
│       ├── dashboard/            # جلب وتحليل بيانات الطالب
│       ├── grades/               # جلب وتحليل السجل الأكاديمي
│       ├── schedule/             # جلب وتحليل جدول الامتحانات
│       └── plan/                 # جلب وتحليل الخطة الدراسية
├── lib/
│   ├── upstream/client.ts        # عميل الاتصال الأصلي (إدارة كوكيز Barracuda WAF و Tomcat)
│   ├── parsers/                  # محركات التحليل Cheerio (دوال نقية)
│   ├── schemas/                  # مخططات Zod لضمان دقة البيانات 100%
│   └── session.ts                # إدارة الجلسة المشفرة iron-session
└── fixtures/                     # ملفات HTML مرجعية للاختبارات
```

## التشغيل السريع

### 1. المتطلبات:
- Node.js 18+ (تم الاختبار والتوافق على Node 24)
- npm

### 2. تثبيت الحزم:
```bash
npm install
```

### 3. إعداد متغيرات البيئة:
انسخ الملف `.env.example` إلى `.env.local`:
```bash
cp .env.example .env.local
```

### 4. تشغيل خادم التطوير:
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3000/login`

### 5. تشغيل اختبارات الـ Parsers (Vitest):
```bash
npm run test
```

## الأقسام المدعومة

1. **تسجيل الدخول (Login):**
   - جلب وتمرير مباشر لرمز التحقق البشري (CAPTCHA) من خادم الجامعة.
   - حفظ جلسة الاتصال وتمرير كوكيز جدار الحماية (Barracuda WAF).
2. **الرئيسية (Dashboard):**
   - المعدل التراكمي والفصلي.
   - الساعات المقطوعة ونسبة الإنجاز نحو التخرج (132 ساعة).
   - الكلية، التخصص، المرشد الأكاديمي، الحالة الأكاديمية.
   - مستكشف الحقول الأصلية (Data Parity Inspector).
3. **العلامات والسجل الأكاديمي (Grades & Transcript):**
   - عرض فصول الطالب كاملة مع شارات ملونة للمعدلات والعلامات.
   - بحث فوري عن أي مادة برقمها أو اسمها.
   - تصفية حسب الفصل الدراسي.
4. **الجدول والامتحانات (Schedule & Exams):**
   - تبويب مواعيد وقاعات الامتحانات النصفية والنهائية وأرقام الجلوس.
   - تبويب المحاضرات الأسبوعية والقاعات والمدرسين.
5. **الخطة الشجرية (Study Plan):**
   - شريط تقدم الساعات المنجزة والمتبقية.
   - تصنيف المواد: منجزة، مسجلة، متبقية.
